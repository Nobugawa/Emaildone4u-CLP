How an email address is built
jane@joesplumbing.comyour web address (domain)
  • Mailbox name — the part before the @. It can be anything you like: a first name (jane) or a role (orders, info, hello). It doesn’t have to match your own name.
  • @ — means “at”. Always in the middle.
  • Domain name — the main part of your web address (joesplumbing).
  • Top-level domain — the ending (.com, .net, .co).
Domain name + top-level domain = your web address (domain), like joesplumbing.com. That’s what step 2 asks for.
